# CEDT Hub

One web app for every CEDT platform: MyCourseVille, CEDT Grader, Talent Journey, CEDT Intern
Portal, Nisitez, CEDT-ICES and more. Log in once with Chula SSO or MyCourseVille and see every
deadline, announcement and event in one place. An AI assistant helps with schedule, calendar,
notes and community.

> Status: early development. Not affiliated with Chulalongkorn University or the CEDT program.

- Production: https://hub.witsanupong-kolakul.com (`master`)
- Staging: https://dev.hub.witsanupong-kolakul.com (`dev`)

## Stack
