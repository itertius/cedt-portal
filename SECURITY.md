# Security Policy

CEDT Hub handles student accounts and OAuth tokens, so security reports matter a lot.

## Reporting a vulnerability

**Do not open a public issue.** Report privately through
[GitHub Security Advisories](https://github.com/itertius/cedt-portal/security/advisories/new).

Include what is affected, steps to reproduce, and the impact you expect. You should get a reply
within 7 days. Please give us a reasonable time to fix the issue before you disclose it.

## Supported versions

Only the latest deploy of `master` (https://hub.witsanupong-kolakul.com) gets security fixes.
